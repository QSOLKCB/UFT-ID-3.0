## FR1. No unrestricted sign for finite Shannon-entropy change

**Claim class:** `COUNTEREXAMPLE`

Consider the broad class of finite-state probability dynamics containing stochastic maps, deterministic bijections, and deterministic many-to-one maps. Let

```text
H(p) = -sum_i p_i log2 p_i.
```

Within this class, two states already suffice to realise every sign of one-step Shannon-entropy change.

### Positive

Start from

```text
p0 = (1,0)
```

and apply the row-stochastic map

```text
K+ = [[1/2,1/2],
      [1/2,1/2]].
```

Then

```text
p1 = (1/2,1/2),
H(p0)=0,
H(p1)=1,
Delta H = +1 bit.
```

### Zero

Any permutation preserves Shannon entropy. For example,

```text
(1/4,3/4) -> (3/4,1/4)
```

has `Delta H = 0`.

### Negative

Starting from

```text
p0=(1/2,1/2),
```

a deterministic merge `0->0, 1->0` gives

```text
p1=(1,0),
Delta H=-1 bit.
```

### Conclusion

There is no common sign of `Delta H` across this unrestricted finite-dynamics class.

**Scope limit:** the positive example does not refute a theorem whose premises exclude stochastic mixing, environmental input, or source randomness. A counterexample counts only against a proposition whose domain includes it.

Executable witness:

```bash
python3 experiments/counterexamples/finite_entropy_signs/run.py
```

## FR2. Deterministic processing cannot increase Shannon entropy

**Claim class:** `PROVED`

Let `X` be a finite discrete random variable and let

```text
Y = f(X)
```

for a deterministic function `f`. Then

```text
H(Y) <= H(X).
```

### Proof

Because `Y` is a deterministic function of `X`,

```text
H(Y|X)=0.
```

The chain rule gives

```text
H(X,Y)=H(X)+H(Y|X)=H(X)
```

and also

```text
H(X,Y)=H(Y)+H(X|Y).
```

Therefore

```text
H(X)=H(Y)+H(X|Y) >= H(Y).
```

Equality holds when `H(X|Y)=0`, for example when `f` is injective on the occupied support.

### Status relative to UFT-ID

This is established Shannon theory, not a novel UFT-ID theorem. Its role here is to identify a clean restricted monotonic regime that any comparison with a broad infodynamic law must distinguish from stochastic or source-driven dynamics.

Foundational source: C. E. Shannon, *A Mathematical Theory of Communication* (1948), DOI `10.1002/j.1538-7305.1948.tb01338.x`.

## FR3. Coarse-graining can reverse the observed entropy sign

**Claim class:** `COUNTEREXAMPLE`

Take the fine-grained trajectory

```text
p0=(1/2,1/2,0,0)
p1=(1/2,0,1/2,0),
```

which is generated by exchanging fine states 2 and 3. The fine-grained Shannon entropy is one bit at both times.

Define partition A by

```text
{{1,2},{3,4}}.
```

The observed trajectory is

```text
(1,0) -> (1/2,1/2),
```

so

```text
Delta H_A = +1 bit.
```

Define partition B by

```text
{{1,3},{2,4}}.
```

The same fine trajectory is observed as

```text
(1/2,1/2) -> (1,0),
```

so

```text
Delta H_B = -1 bit.
```

Therefore

```text
sign(Delta H_observed)
```

is not invariant under arbitrary changes of coarse-graining, even when the underlying fine-grained dynamics are a Shannon-entropy-preserving permutation.

This is why representation-sensitive work should carry an explicit observation/partition contract such as `I_{O,mu,P}`.

Executable witness:

```bash
python3 experiments/representation/coarse_graining/run.py
```

## FR4. Proposal/recovery information decomposition

**Claim class:** `PROVED`

For a discrete constrained step

```text
s_n --F--> x_{n+1} --Pi--> s_{n+1},
```

assume the same information functional `I` is defined at all three states and that

```text
I(s_n), I(x_{n+1}), I(s_{n+1})
```

are finite real values. Define

```text
Delta I_proposal = I(x_{n+1}) - I(s_n)
Delta I_recovery = I(s_{n+1}) - I(x_{n+1}).
```

Then

```text
Delta I_total
= I(s_{n+1}) - I(s_n)
= Delta I_proposal + Delta I_recovery.
```

### Proof

Direct cancellation of the finite intermediate term `I(x_{n+1})`.

### Scope limit

This proved result is the **finite-valued discrete specialization** only. If `I` can take extended-real values such as `+infinity`, a difference such as `+infinity - +infinity` may be undefined and the identity cannot be invoked without additional conventions or hypotheses. Continuous, stochastic, path-dependent, or non-separable proposal/recovery generalizations remain separate theorem work.

## FR5. Recovery admissibility does not imply information decrease

**Claim class:** `COUNTEREXAMPLE`

Let

```text
S={a,b,c}
A={a,b}
Pi(c)=b
```

and define an information functional

```text
I(a)=0,
I(c)=1,
I(b)=2.
```

Recovery sends inadmissible `c` to admissible `b`, but

```text
Delta I_recovery = I(b)-I(c)=+1.
```

Thus

```text
recovery into A
```

does not by itself imply

```text
Delta I <= 0.
```

A monotonicity theorem requires an additional relation between admissibility/recovery and the selected information functional.

## FR6. Multiplicity entropy extremum in the 2026 polygon source

**Claim class:** `COUNTEREXAMPLE`

Primary source under audit: Melvin M. Vopson, *The Role of Information Entropy in Symmetry of Euclidean Polygons*, **Entropy** 28(5), 564 (2026), DOI `10.3390/e28050564`.

The source's general argument on pp. 3-4 fixes total system size `N`, describes positive multiplicities `g_i`, uses probabilities `p_i=g_i/N`, and identifies equal multiplicity as the minimum-entropy condition. Because the source does not cleanly freeze the represented-category count `n` throughout the global optimization, FR6 separates two mathematical readings.

### FR6A. Fixed N and fixed n

For positive integer multiplicities

```text
g_i > 0,
sum_i g_i = N,
```

with fixed `N` and fixed category count `n`, set

```text
p_i=g_i/N
```

and

```text
H=-sum_i p_i log2 p_i.
```

The uniform probability vector maximises Shannon entropy. Hence, when `N` is divisible by `n`, equal multiplicities `g_i=N/n` are a **maximum**, not a minimum. For integer counts when divisibility fails, the maximum is attained by the most balanced counts, differing by at most one.

Over positive integer counts, the minimum is attained by the most concentrated vector, up to permutation:

```text
(N-n+1,1,...,1).
```

For `N=6,n=2`:

```text
H(3,3)=1 bit
H(5,1) ~= 0.650022421648 bit.
```

### FR6B. Fixed N with n variable

If only `N` is fixed and `n` may range from `1` to `N`, then

```text
minimum: n=1, counts=(N),       H=0
maximum: n=N, counts=(1,...,1), H=log2(N).
```

Thus equal multiplicity alone does not characterize a nontrivial global minimum. This variable-`n` classification also reproduces the source's all-distinct maximum endpoint `g_i=1`, `n=N`.

The detailed source map and executable audit are in:

```text
research/vopson/POLYGON_2026_AUDIT.md
experiments/reproduction/vopson_2026_polygons/run.py
```

### Scope limit

FR6 corrects only the source's general multiplicity-extremum classification. It does **not** imply that every polygon-specific numerical comparison is wrong. Polygon examples that change the effective descriptor category count or descriptor definition must be reproduced separately under their actual observation map.
