# Counterexample and Scope Matrix

This matrix prevents a valid small counterexample from being aimed at a proposition whose premises exclude it.

| Result | What it establishes | Fair target | What it does **not** establish |
|---|---|---|---|
| `FR1` two-state positive/zero/negative signs | No common Shannon sign over a class containing stochastic mixing, permutations and many-to-one maps | An unrestricted entropy-direction claim whose domain includes those maps | It does not refute a deterministic-only theorem |
| `FR2` \(Y=f(X)\Rightarrow H(Y)\le H(X)\) | A clean restricted monotonic regime | Deterministic processing with fixed observation contract and no extra source variable | It does not prove a universal physical law |
| `FR3` coarse-graining sign reversal | Same fine trajectory can acquire opposite observed signs under different partitions | Representation-independent or partition-robust sign claims | It does not show every physically privileged observable is arbitrary |
| `FR4` proposal/recovery decomposition | Exact finite-valued discrete algebraic decomposition | Clean two-stage constrained steps | It does not define physical production/loss terms |
| `FR5` admissible recovery can raise declared \(I\) | Admissibility alone gives no entropy direction | Any theorem inferring \(\Delta I\le0\) from recovery alone | It does not reject recovery rules explicitly optimising the same \(I\) |
| `FR6` multiplicity extremum correction | Balanced positive counts maximise Shannon entropy at fixed `(N,n)`; variable-`n` extrema differ | The source’s general multiplicity extremum argument | It does not invalidate every polygon descriptor calculation |

## Source-fidelity gate

For `CL-SLI-PUBLISHED`, FR1 and FR3 are adversarial probes, not yet a complete source-specific refutation. The exact source state spaces, alphabets, transitions and boundaries must first be frozen.

For `CL-POLYGON-EXTREMUM`, the source formulation has been mapped sufficiently to support a bounded `COUNTEREXAMPLE` classification, with the scope limits retained beside the result.
