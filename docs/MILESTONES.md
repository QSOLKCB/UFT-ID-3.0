## Formal verification

Lean remains a post-freeze hardening stage. Machine proof verifies deductions
from assumptions. It does not validate the physical truth of those assumptions.

## Release policy

While the research architecture is pre-1.0:

- patch releases correct implementation or documentation without increasing
  scientific authority;
- minor releases add reproducible evidence surfaces, corpus capabilities, or
  scoped results;
- `v1.0.0` requires source reproduction, theorem/notation freeze, adversarial
  review, reproducible headline results, and explicit limitations.

Every tagged research release should record the commit, schema versions,
supported runtimes, validation command, deterministic fingerprints, claim
changes, known limitations, and citation metadata.
