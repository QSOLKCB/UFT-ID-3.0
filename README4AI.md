# UFT-ID 3.0: AI Bootstrap

This file is the preferred entry point for AI agents working in this repository.

## Mission

Develop UFT-ID 3.0 as a rigorously scoped theory-and-experiment program for constraint-governed information dynamics. Preserve a hard distinction between formal results, diagnostics, empirical evidence, interpretation, and speculation.

## Canonical object

```text
U = (S, A, F, Pi_lex, O, T, I, C)
```

Interpretation:

- `S`: total state space
- `A`: admissible subspace
- `F`: proposed evolution
- `Pi_lex`: deterministic recovery map
- `O`: observation/coarse-graining map
- `T`: regime-transport map
- `I`: explicitly declared information functional
- `C`: constraint structure

Do not specialize these symbols to E8, SU(3), LQG, cognition, AGI, or any other ontology unless the target document explicitly enters an interpretive or speculative layer.

## Canonical inherited constraint core

The stable UFT-ID 2.0 constraint-first lineage supplies:

```text
S        total/overcomplete state space
A        admissible subspace
r(s)     residual or distance from admissibility
Phi(s)   quadratic tension functional
Phi_crit threshold for corrective event
Pi_lex   unique deterministic recovery via fixed tie-breaking order
Delta    impulse object s^- - s^+
```

Treat this as the main formal inheritance. Earlier lattice-specific and ontology-heavy versions are historical specializations, not axioms of UFT-ID 3.0.

## Claim classes

Every nontrivial claim should be classifiable as exactly one of:

- `DEFINITION`
- `THEOREM_TARGET`
- `PROVED`
- `COUNTEREXAMPLE`
- `DIAGNOSTIC`
- `EMPIRICAL`
- `INTERPRETIVE`
- `SPECULATIVE`
- `NONCLAIM`

Do not silently promote a claim between classes.

## Hard rules

1. Never claim that information is matter, mass, energy, spacetime, consciousness, or a physical field merely because a representation uses physical mathematics.
2. Never infer a universal information law from examples without a quantified domain and explicit assumptions.
3. Never treat Shannon entropy, thermodynamic entropy, von Neumann entropy, relative entropy, algorithmic information, observational entropy, and mutual information as interchangeable.
4. Never compare information quantities across different partitions, alphabets, reference measures, boundaries, or coarse-graining maps without declaring the bridge.
5. Never turn a cross-domain correspondence into a shared causal mechanism without evidence.
6. Never describe simulation output as proof.
7. Never describe a successful fit as a unique explanation.
8. Never claim Lean verification unless checked Lean source exists and builds.
9. Never attack an author personally. Critique equations, assumptions, data, inference, and scope.
10. Prefer counterexamples, sensitivity tests, null models, preregistered comparison rules, and exact reproduction over rhetoric.

## Vopson comparison

The repository deliberately tests Vopson's infodynamics program at its strongest published form. Do not straw-man it.

Key tracks:

- mass-energy-information equivalence;
- universal or quasi-universal information-entropy monotonicity;
- digital information systems;
- genomic mutation claims;
- atomic/Hund-rule claims;
- symmetry claims;
- gravity/data-compression claims;
- language-diversity claims;
- simulation-hypothesis inference.

For each track, reconstruct the exact information functional, state representation, dynamics, assumptions, data, and inferential step before attempting criticism.

## Lean

Lean is deferred until definitions stabilize. The future formalization should begin with finite state spaces and the smallest provable surface:

- admissibility predicates;
- residual zero iff admissible under stated assumptions;
- existence/uniqueness of finite lexicographic recovery;
- recovery lands in `A`;
- special-case monotonicity theorem;
- explicit finite counterexample to universal monotonicity where appropriate;
- representation/transport invariants only after they are mathematically specified.
